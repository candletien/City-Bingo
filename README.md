# 🧳 City Bingo

เกมบิงโกสำหรับนักเดินทาง — เลือกเมือง รับการ์ดภารกิจแบบสุ่ม แล้วทำภารกิจระหว่างเที่ยวให้ครบแถวเพื่อทำบิงโก

## ฟีเจอร์
- เลือกเมือง: กรุงเทพฯ, เชียงใหม่, ภูเก็ต, โตเกียว, โซล, ปารีส หรือ "เมืองไหนก็ได้"
- ขนาดการ์ด 3×3 / 4×4 / 5×5 (การ์ด 5×5 มีช่อง FREE ตรงกลาง)
- เพิ่มภารกิจของตัวเองได้
- ติ๊กภารกิจ แนบรูปเป็นหลักฐาน และเขียนบันทึกสั้น ๆ
- ตรวจบิงโกอัตโนมัติ (แนวนอน แนวตั้ง แนวทแยง) พร้อมคอนเฟตติ และมีโหมด Blackout
- คะแนน: ภารกิจละ 10, บิงโกแถวละ 50, Blackout +200
- อัลบั้มทริปรวมรูปและบันทึก
- แชร์ผลเป็นตารางอีโมจิ (Web Share หรือคัดลอกลงคลิปบอร์ด)
- บันทึกความคืบหน้าไว้ในเครื่อง (localStorage) ใช้งานออฟไลน์ได้หลังเปิดครั้งแรก

## วิธีรัน
เป็นเว็บแบบ static ไม่ต้อง build:

```bash
python3 -m http.server 8000
# เปิด http://localhost:8000
```

deploy ขึ้น GitHub Pages / Netlify / Vercel ได้ทันที

## โครงสร้าง
- `index.html` — หน้าจอเริ่มเกม, บิงโกการ์ด, dialog ต่าง ๆ
- `css/style.css` — สไตล์แบบ mobile-first รองรับ dark mode
- `js/data.js` — รายการภารกิจ (ทั่วไป + รายเมือง) แก้/เพิ่มเมืองได้ที่นี่
- `js/app.js` — ตรรกะของเกม
